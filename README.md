## Power BI Templates (v2.0)
Auvik's Power BI templates for reporting


We provide two Power BI `.pbit` templates so you can choose between **maximum reporting depth** or **faster load/refresh performance**.

### Download

- **Auvik Power BI Template 2.0 (Full)**  
  Best for in-depth reporting with the full set of reports and metrics, including **device performance** data.  
  File: `templates/v2.0/Auvik Power BI Template 2.0 (Full).pbit`

- **Auvik Power BI Template 2.0 (Performance)**  
  Optimized for faster load times and refresh performance. Excludes **device performance** metrics, but includes **availability** data.  
  File: `templates/v2.0/Auvik Power BI Template 2.0 (Performance).pbit`

### Which template should I use?

- Choose **2.0 (Full)** if you want the most complete reporting and you’re okay with larger datasets / longer refresh times.
- Choose **2.0 (Performance)** if you want faster load/refresh times and don’t need device performance metrics.

### Requirements

- Microsoft Power BI Desktop (latest recommended)
- Auvik API credentials with access to the required reporting data
- Internet access to reach the Auvik API

> Need help getting started? Refer to Auvik documentation for setup and usage instructions.
